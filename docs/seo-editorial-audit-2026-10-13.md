Не додано весь каталог референсу: маркетплейси нових/уживаних авто, власні рейтинги, підписки, покупки спорядження або великі нові рубрики потребують власного контенту й операційної спроможності. Брендинг, тексти та вимірювання Car and Driver не копіювалися. Світла/темна тема AutoGlob збережені. Tools містить лише сім калькуляторів.

## Технічна перевірка

- Унікальні title/description, канонічні адреси, OG/Twitter та JSON-LD перевірено для всіх індексованих сторінок.
- Sitemap містить рівно 33 потрібні URL. Дати змін і картинки оновлено разом зі сторінками.
- Локальні посилання, анкори, файли картинок, декларації srcset та розміри перевірено статично; немає виявлених битих посилань або осиротілих індексованих сторінок.
- Порожній alt у декоративної картинки біля вже підписаного інструмента є коректним, його не рахували як помилку. Legacy article.html і 404 мають noindex; справжня відсутня URL повертає HTTP 404.
- Арифметику та поведінку сімох калькуляторів перевірено контрольними прикладами. Для VIN перевірено валідацію й відображення відповіді API з тестовими даними; доступність зовнішньої бази є окремою перевіркою.
- CO2 уже використовував правильні фактори EPA 8.887 / 10.180 кг на американський галон. Їх підтверджено, формулу без потреби не змінювали.
- Shared script перевірено із забороненим localStorage та пошуком серед 24 статей/інструментів.
- Нові файли картинок декодуються, не порожні; під час завантаження звіряється Git blob SHA. Візуальне приймання живої версії записується окремо після розгортання.

## Межі та наступні рішення власника

Пошукова індексація і позиції не підтверджуються самим sitemap. Без даних Search Console не можна достовірно назвати обрані Google canonical, причини виключення, запити чи CTR. Аналогічно не заявляємо вигаданих балів Lighthouse, CrUX або Core Web Vitals. Наступний корисний крок — підключити Search Console для AutoGlob, подати sitemap і перевірити Page Indexing / URL Inspection / Performance.

У коді немає підтвердженого ідентифікатора AdSense або аналітики AutoGlob. Код TTN Finance не додавали. Комерційний запуск вимагатиме власних реквізитів і фактичного опису встановлених сервісів; жодні ідентифікатори не вигадували. Наразі є публічний канал виправлень через GitHub; приватна адреса контактів не надана.

Збережені зображення BMW/Honda/Bugatti є ілюстраціями. Виправлені підписи не обіцяють технічної або документальної точності невстановлених початкових референсів. Якщо в майбутньому буде доведена конкретна невідповідність деталі, виправляти її треба індивідуально — без автоматичної заміни всього комплекту.
