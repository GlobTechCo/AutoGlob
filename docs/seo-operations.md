# AutoGlob SEO operations

Canonical site: https://globtechco.github.io/AutoGlob/

Implemented: unique metadata, canonical URLs, language, social images, Article/WebPage/WebSite/Organization/BreadcrumbList/WebApplication/ItemList JSON-LD, human-readable tool guides, related tool links, canonical/image sitemap, custom noindex 404 and legacy redirect noindex.

WebApplication describes the seven tools. No invented aggregateRating or reviews were added. This markup is not a claim of eligibility for Google's software rich results: those results require a genuine rating or review. Visible questions were not marked as FAQ rich results.

## Google Search Console

1. Use the URL-prefix property https://globtechco.github.io/AutoGlob/.
2. Obtain the real HTML verification file or meta-tag token from the property's owner account; add that exact file or token to this repository. Do not use TTN Finance verification or Analytics identifiers.
3. Submit https://globtechco.github.io/AutoGlob/sitemap.xml in the verified property.
4. Inspect the homepage, tools hub and each calculator with URL Inspection. Request indexing for those URLs if appropriate.
5. Monitor indexing, selected canonicals, crawl errors and search queries. Technical setup does not guarantee indexing or rankings.

The repository's /AutoGlob/robots.txt is a project-level copy. Google reads https://globtechco.github.io/robots.txt at the host root. Host-root changes require the corresponding owner-level site repository or a dedicated domain. Other projects must not be altered without explicit authorization.

No Google Analytics was added. No verification token was invented. Search Console ownership and sitemap submission were not completed through the code update.

## Publishing checklist

For a new article: make it reachable from a section/archive, set a unique title and description, use a self-referencing canonical URL, match the visible author and publication date in Article markup, provide an accurate descriptive image, and add the canonical URL to sitemap.xml. lastmod must reflect a real significant page change.
